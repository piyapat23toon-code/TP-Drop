เวอร์ชันเดิมใช้เพียง BroadcastChannel ซึ่งทำงานได้เฉพาะในเบราว์เซอร์เดียวกัน แต่ใน TP Drop เวอร์ชันนี้ได้ติดตั้ง PeerJS (WebRTC DataChannel) พร้อม STUN Server ของ Google ทำให้คอมพิวเตอร์และมือถือที่เปิดเว็บผ่าน Wi-Fi หรือเน็ตมือถือสามารถส่งไฟล์หากันได้จริงโดยไม่ต้องตั้งเซิร์ฟเวอร์หลังบ้านเอง

📦 วิธีนำไฟล์นี้ไปเปิดใช้งานบน GitHub Pages ฟรี:

  1. สร้าง Repository ใหม่บน GitHub (ตั้งเป็น Public)
  2. อัปโหลดไฟล์นี้โดยตั้งชื่อว่า index.html
  3. ไปที่เมนู Settings → Pages ของ Repository
  4. ตรงหัวข้อ Branch เลือก main แล้วกด Save
  5. รอประมาณ 1 นาที คุณจะได้ลิงก์ https://ชื่อคุณ.github.io/ชื่อโปรเจกต์/ สามารถเปิดใช้งานได้ทั้งบนคอมและมือถือทันที!

💡 เคล็ดลับการเชื่อมต่อที่รวดเร็วที่สุด:

เมื่อนำขึ้น GitHub Pages แล้ว ให้เปิดหน้า "รับไฟล์" บนคอมพิวเตอร์ แล้วใช้กล้องมือถือสแกน QR Code บนหน้าจอ มือถือจะเปิดลิงก์พร้อมจับคู่ให้อัตโนมัติโดยไม่ต้องพิมพ์รหัสเองเลย

📲 วิธีใช้งาน TP Drop

1. ดูรหัส 6 หลักที่เครื่องปลายทาง

เปิดเว็บ TP Drop บนเครื่องที่ต้องการรับไฟล์ กดแท็บ "รับไฟล์ (ดูรหัส)" จะเห็นรหัสตัวเลข 6 หลัก และ QR Code

2. กรอกรหัสหรือสแกน QR เพื่อจับคู่

ในเครื่องส่ง ให้นำรหัส 6 หลักมากรอก ระบบจะเชื่อมต่อผ่าน WebRTC P2P ข้ามเครื่องให้ทันที (ไฟสถานะด้านบนจะเปลี่ยนเป็นสีเขียว)

3. ส่งได้ทั้งสองทาง (Bi-directional)

เมื่อจับคู่กันแล้ว ทั้งสองเครื่องสามารถลากไฟล์วาง กด Ctrl+V วางรูปภาพ หรือส่งข้อความหากันได้ทันที
